# 🔍 SQL Murder Mystery Investigation

## 📌 Project Overview

This project is a SQL-based investigation of a  murder mystery using a relational SQLite database. The goal was to analyze clues stored across multiple tables, identify the murderer, and uncover the person behind the crime.

The investigation follows an evidence-based approach, starting from the crime scene report and progressively narrowing down suspects using SQL queries.

## 🛠️ Tools Used

* SQL (SQLite)
* Python
* Pandas
* Jupyter Notebook

## 💡 SQL Skills Demonstrated

* Data exploration using `SELECT`
* Data filtering with `WHERE`, `AND`, and `OR`
* Pattern matching using `LIKE`
* Filtering multiple values using `IN`
* Sorting and limiting query results
* Combining related tables using `JOIN`
* Working with relational database relationships

## 🔎 Investigation Process

1. Explored the database and identified relevant tables.
2. Located the murder case in the crime scene reports.
3. Identified and investigated key witnesses.
4. Analyzed witness interview transcripts to extract clues.
5. Used gym membership information to narrow down potential suspects.
6. Connected related tables using SQL JOIN operations.
7. Used vehicle information to identify the murderer.
8. Analyzed additional evidence to identify the mastermind behind the crime.

## 🏆 Final Result

Using SQL queries and evidence gathered throughout the investigation, I successfully identified the murderer and the person responsible for the crime.

The project demonstrates how SQL can be used to navigate a relational database, connect information across multiple tables, and solve a problem through step-by-step data analysis.
